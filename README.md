# NEXUS-Launcher

NEXUS Launcher Beta 是一个面向 Android 设备的 Minecraft Java 版启动器项目。

项目介绍

NEXUS Launcher 致力于提供简洁、现代化的 Minecraft 启动体验。

设计特点

黑色与荧光绿色科技风格

版本管理界面

模组管理规划

整合包、资源包和光影包管理规划

内存分配设置

国内及海外下载源支持规划

项目状态

目前项目仍处于开发和测试阶段。

注意：当前源码骨架不代表完整可运行的 Minecraft 启动器。 Microsoft 登录、完整游戏文件下载、Java 运行环境管理及游戏启动功能仍需开发和测试。

构建

项目计划使用 GitHub Actions 自动构建 Android APK。

构建是否成功、APK 是否生成及上传，需要以对应的 GitHub Actions 运行记录为准。

设备要求

Android 设备

最低 Android 版本以实际构建配置为准

许可证

许可证尚待项目维护者确定。
